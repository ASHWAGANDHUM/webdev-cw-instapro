# Instapro

MVP социальной сети для обмена фотографиями.

## Реализованная функциональность

- Динамическая лента постов из API
- Добавление поста с загрузкой фотографии в облако
- Страница постов отдельного пользователя
- Лайки и дизлайки без перезагрузки страницы (для авторизованных)
- Относительное время публикации через date-fns с русской локалью
  («N минут назад»)
- Экранирование пользовательского контента (защита от HTML-инъекций)

## Стек

Ванильный JavaScript, ES-модули. Без сборщика — запуск через Live Server.
